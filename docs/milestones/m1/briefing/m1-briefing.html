三、实现与迭代史：双闸门如何逼近真实实现

迭代 1：骨架建立，机械通过不等于语义通过

提交 ab47138 建立初版 workspace、工具骨架、CI 与 Docker skeleton。第一轮独立评审结论为未通过独立验收，列出 F01～F12。核心问题包括：冻结 YAML 仅被嵌入而未生成 42 个类型；所谓 Draft 校验只是字符串判断；drift 测试是同函数自等；66 manifest 只有分组计数；runner 自检不读取真实清单；fake/stub 只是打印骨架文字；capability 工具无精确 inventory；CI、runtime closure、target 和出口签核也存在缺口。R1 说明：命令能 exit 0，只代表现有断言成立，不能代替冻结验收语义。

迭代 2：把占位门禁改为真实负向门

f0ea823 与 a4116af 针对 F01～F12 引入固定版本 contract-gen、真实生成输出比较、Draft 2020-12 与标准 JCS 库、逐行 66 manifest、loopback fake/stub、34 项 inventory、拆分 CI jobs、runtime closure 和 Linux target。尤其 drift-real、manifest/inventory 损毁副本让门禁具备“真负向”能力：错误资产必须非零退出并恢复工作树。

R2 仍给出未通过独立验收，新增 F13～F15：42 个生成名称仍是透明 serde_json::Value 包装；stub 实际只覆盖少数请求却固定声称 13 路由；capability 只按前缀计数，同数量替换为未知 ID 仍可能通过。这一轮揭示了“看起来真实”的另一类假阳性。

迭代 3：由权威输入派生并精确 fail-closed

3f6791b、137c618、790ea32 关闭 F13～F15。生成器递归映射 object properties、required/optional、enum、oneOf、allOf、$ref、array 与 additionalProperties，输出可编译强类型；golden 测试证明属性、枚举、联合变化会改变生成物。reference stub 用唯一 ROUTES registry 同时驱动服务分发、客户端 probe 和计数，逐条验证 13 路由并要求明确 NOT_IMPLEMENTED。capability-report 将 WUI-001..021、DSHD-001..004、OUT-001..009 构成精确集合，并拒绝未知、缺失、错 kind、非法 status 与证据不一致。

迭代 4：Windows socket 稳定性收敛

faeab2f 修复 reference-stub/fake-harness 在 Windows 回环自检中的 WSA 10004/10053 等瞬时错误与关闭撕裂。连接采用最多 3 次有界尝试和 25/50ms 退避；响应以 Content-Length 判定完整；listener 以非阻塞循环和完成信号退出，随后 join；bind/accept/connect/read/write/shutdown 均显式传播错误。结果从“遇到瞬时 IO 可能恐慌”收敛为“有界重试、完整响应判断、优雅关闭”。

独立 R3：四维度全部 PASS

c1c25ee 记录第三轮独立评审。评审逐项对质实现、代码与真实复跑，确认 R2 三项缺口和 Windows 稳定性缺陷关闭，且未新增 F16。由此形成最终结论“通过独立验收”。整个过程体现双闸门价值：机械门负责可重复执行和真负向，独立评审负责识别断言与冻结语义之间的差距，两者缺一不可。

六、遗留事项与下一步

  1. 解除 CI 外阻并转正：由账户所有者处理 GitHub Actions 计费限制；恢复后从新 clone、无缓存执行同一次完整 pipeline，保存 run URL/ID 与原始日志，再将 AC-01/VM-01 从 BLOCKED-EXTERNAL 重新评估。
  2. 补齐 Docker 原始证据：在 CI 或本机 Docker 可用后执行 skeleton build 与 smoke，记录 image/build log、入口确定行为和 runtime closure 边界，再评估 AC-04/VM-04 的 PENDING。
  3. 时点要求：上述两项属于外部依赖和证据缺口，不阻塞 M1 工程骨架的本地独立验收结论，但应在进入 M2 的稳定交付节奏前解决，且不得以静态检查替代运行证据。
  4. M2 展望：在现有 driver、manifest、生成契约和冻结边界内增量实现配置、身份、状态协调、进程守护与 Harness 生命周期，不改变 M1 工具的诚实统计语义。
